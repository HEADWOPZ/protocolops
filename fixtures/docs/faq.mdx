# FAQ

## Is this financial advice?

No. Helios docs describe software. They are not an offer to buy, stake, or use any token.

## Which wallets work?

Injected EIP-1193 wallets and WalletConnect v2. See [Connect a wallet](/connect-wallet).

## Where is the bridge documented?

It is not in this docs set yet. Treat any third-party bridge UI as unreviewed.

## Can I use hHLS in other protocols?

Third-party operators are out of scope for this FAQ. Do not assume Helios covers losses outside the vault.

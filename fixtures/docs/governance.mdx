# Governance

Helios uses token-weighted voting. hHLS held in the vault is checkpointed each epoch.

## Propose

Addresses with at least the current proposal threshold can submit a HIP. The threshold is an on-chain parameter.

## Vote

Voting is open for five epochs after a proposal leaves review. Delegates may vote on behalf of vault shares.

## Execute

Passed proposals enter a timelock. Anyone can execute after the delay if the payload still matches the committed hash.
